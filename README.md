# Vrinda Store Data Analysis

##  Project Overview

This project analyzes retail sales data from Vrinda Store using Microsoft Excel. The objective is to transform raw sales data into meaningful business insights related to sales performance, customers, orders, and product categories.

The project demonstrates practical Excel-based data analysis and visualization skills that can be applied to real-world business decision-making.

---

##  Project Objectives

- Analyze overall sales performance.
- Identify sales trends and patterns.
- Understand customer purchasing behavior.
- Analyze sales by different categories and channels.
- Identify important business insights from the dataset.
- Present findings using Excel-based charts and dashboards.

##  Project Analysis

The analysis focuses on different aspects of the store's sales data, including:

- Sales performance
- Customer analysis
- Product/category performance
- Order trends
- Sales distribution
- Business performance indicators

Pivot Tables and charts were used to summarize the raw data and make the results easier to understand.
